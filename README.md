# XivLens

XivLens is a technical paper atlas. Each paper is a curated, multi-section visual essay built from typed React modules and shared visualization primitives.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

## Add a Paper

See [docs/add-paper.md](docs/add-paper.md). The intended workflow is: send Codex a paper link, let it read the paper, design the conceptual story, implement a TSX paper module, and register it in the atlas.
